# The Long Story — Restaurant Web Technology Project

## Files
- index.html — complete website structure
- style.css — chic responsive design
- script.js — menu filtering, cart, bill calculation and reservation validation
- images/ — restaurant photos supplied for the project

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. For the best experience, use VS Code with the Live Server extension and choose "Open with Live Server".

## Technologies
HTML5, CSS3, JavaScript, Google Fonts, LocalStorage.

## Main features
- Responsive restaurant homepage
- Interactive menu category filters
- Add-to-cart functionality
- Quantity controls
- Dynamic subtotal, GST and total
- Reservation form validation
- Mobile navigation
- Restaurant photo gallery sections
